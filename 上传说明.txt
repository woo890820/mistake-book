============================================================
  错题本 APP · 上传到 GitHub 的操作步骤
============================================================

【要上传的文件 —— 一共 5 个，都是普通文件，没有文件夹】

  1. main.dart                全部代码
  2. pubspec.yaml             依赖清单
  3. mistake_template.docx    Word 模板
  4. setup.sh                 一键编译脚本
  5. github-workflow.yml      自动编译配置


【操作步骤】

第 1 步：上传这 5 个文件
  - 打开你的 GitHub 仓库
  - 点 "uploading an existing file"
  - 把这 5 个文件全选拖进去（它们都是文件，不是文件夹，能拖成功）
  - 拉到底部点 "Commit changes"


第 2 步：把 github-workflow.yml 改个位置（关键！）
  GitHub 只认固定路径的配置文件，所以要做一次重命名：

  a) 点进刚上传的 github-workflow.yml 文件
  b) 点右上角铅笔图标（编辑）
  c) 点文件名旁的 ... 或直接改路径框里的文件名
     完整路径要改成：.github/workflows/build-apk.yml

  更简单的做法：
  a) 打开 github-workflow.yml，点右上角 "Raw" 或直接全选复制内容
  b) 回仓库首页，点 "Add file" -> "Create new file"
  c) 文件名框里输入：.github/workflows/build-apk.yml
     （打斜杠时 GitHub 会自动创建文件夹，你不用手动建）
  d) 把内容粘进去，点 "Commit changes"
  e) 把原来那个 github-workflow.yml 删掉（点进去 -> 垃圾桶图标）


第 3 步：等编译
  - 仓库顶部点 "Actions" 标签
  - 会看到一条叫「编译 APK」的记录
  - 旁边是黄色小圆点 = 正在编译
  - 等 5-8 分钟，变成绿色对勾 ✓ = 成功
  - 变红色叉 ✗ = 失败，把报错截图发给开发者


第 4 步：下载 APK
  - 点进那次编译记录
  - 页面拉到最下面，找到 "Artifacts" 区域
  - 点 "mistake-book-apk" 下载
  - 下载的是 zip，解压后就是 app-release.apk


第 5 步：装到手机
  - 把 app-release.apk 传到手机（微信文件传输助手最快）
  - 打开卓易通 -> 本地安装 -> 选中这个文件
  - 装完桌面出现「错题本」图标


============================================================
  装好后配置 AI 识题
============================================================

1. 打开 APP，点右上角齿轮图标（设置）
2. 去腾讯云混元控制台创建 API Key：
   cloud.tencent.com/product/hunyuan
   （需实名认证，新用户有免费额度）
3. 回到 APP 设置页：
   - API Key：粘贴你创建的密钥
   - 模型名：填 hunyuan-vision
4. 点「测试连接」，显示成功就点「保存」


============================================================
  如果不想用 GitHub，直接在你电脑上编译
============================================================

把 5 个文件放同一个文件夹，在终端里执行：

    bash setup.sh

脚本会自动组装工程并编译，完成后当前目录会出现「错题本.apk」。
（需要电脑上先装好 Flutter：docs.flutter.dev/get-started/install）


============================================================
  遇到问题
============================================================

Actions 里什么都没有     -> workflow 文件路径不对，检查是否为
                            .github/workflows/build-apk.yml
显示要付费              -> 仓库改成 Public（Settings -> 最下面
                            Danger Zone -> Change visibility）
编译变红                -> 把报错截图发我
AI 提示未配置           -> 去 APP 设置里填 Key
AI 报模型不存在         -> 模型名要填 hunyuan-vision
